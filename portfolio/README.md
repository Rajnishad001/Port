
# Raj Kumar Nishad - Portfolio Website

A modern and responsive personal portfolio website built using React, Vite, and Tailwind CSS. This portfolio showcases my skills, projects, GitHub profile, and contact information in a clean and professional design.

## 📌 Features

- Modern Responsive Design
- Professional Hero Section
- About Me Section
- Skills Showcase
- Featured Projects
- GitHub Profile Section
- Contact Form (EmailJS Integration)
- Resume Download
- Mobile Friendly Navigation
- Smooth Scrolling
- Dark Theme UI
